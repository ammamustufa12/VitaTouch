# VitaTouch

Touch health monitor for a Windows touch laptop. One to five fingers load the corner cards and change the color.

## Run without building

Download this repository and open the whole `VitaTouch-Windows` folder. Run `smart_health_monitor.exe` from inside that folder. The exe needs the dll files and the `data` folder beside it, so do not move the exe out alone.

## Build from source

Flutter 3.32 or newer is required.

```
flutter pub get
flutter run -d windows
```
